Two commands every engineer (and every AI coding agent) leans on: grep and curl

They're decades old. They're also the first thing a code model reaches for when it's working in your repo.

Why these two

grep answers "where is this?" Hand it a string or a regex and it tears through a codebase in milliseconds. When an AI agent needs to find every call site before refactoring a function, it isn't reading files one by one — it's running grep -rn.

curl answers "what does this endpoint actually return?" Headers, status codes, a JSON body you can pipe straight into jq. When an agent is debugging an integration, curl is how it checks reality instead of guessing from the docs.

Why they fit code models so well

  • Text in, text out. A model reads and writes text. Nothing to translate.
  • Composable. One pipe turns five small tools into a one-line pipeline.
  • Everywhere. Same behavior on a laptop, a container, or a CI runner.
  • They fail loudly and specifically. Exit codes and stderr give the model something to reason about.

The lesson isn't "learn old tools." It's that the Unix philosophy — small programs, plain text, clear contracts — turned out to be the ideal interface for machines that think in language.

grep

commandwhat it does
grep -rn "pattern" dir/recursive search with file:line prefixes — the default move
grep -ril "pattern" .case-insensitive, print only matching filenames
grep -E "a|b" fileextended regex (alternation, +, ?, {n})
grep -F "literal.string" filefixed string, no regex — safer and faster for literals
grep -w "word" filewhole-word match only
grep -c "pattern" filecount matching lines
grep -v "pattern" fileinvert: lines that do not match
grep -A3 -B1 "pattern" fileshow 3 lines after, 1 before (-C for both)
grep -o "[0-9]\+" fileprint only the matching part, one per line
grep --include="*.py" -rn "def " .restrict recursion to certain file types
grep -rn "x" . --exclude-dir=node_modulesskip a directory
rg "pattern"ripgrep: same idea, respects .gitignore, much faster on big trees

commandwhat it does
